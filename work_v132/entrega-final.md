# Entrega final — Studio Vandal Co.

## Resumen del proyecto

El proyecto presenta un prototipo web para Studio Vandal Co., un estudio gráfico y digital con lenguaje visual editorial, fuerte contraste, uso de negro, gris cálido, blanco roto y naranja como acento principal.

## Qué se entrega

- Sitio web responsive en HTML, CSS y JavaScript.
- Hero editorial con marca y composición visual.
- Sección Studio con manifiesto y descripción del enfoque.
- Recorrido visual por scroll con piezas del sistema gráfico.
- Portfolio Work con scroll horizontal en escritorio.
- Filtros por categoría: Identity, Poster y Product.
- Modo Index para ver los proyectos en lista.
- Reel con video de recorrido.
- Formulario de contacto con validación básica.
- Cursor personalizado para escritorio.
- Mejoras de accesibilidad y compatibilidad con reducción de movimiento.

## Interacciones principales

1. Navegación interna con scroll suave.
2. Menú responsive en mobile.
3. Estados activos en navegación.
4. Aparición progresiva de contenido al hacer scroll.
5. Movimiento horizontal del portfolio a partir del scroll vertical.
6. Filtro de proyectos por categoría.
7. Cambio entre Overview e Index en la sección Work.
8. Validación de campos requeridos en Contact.

## Conclusión

La entrega cumple con una primera versión funcional y presentable del prototipo. El sitio comunica la identidad de Studio Vandal Co. y muestra cómo el sistema gráfico puede vivir en una experiencia web editorial, interactiva y responsive.

## Ajuste de portfolio tipo reel

- Se reemplazo el scroll horizontal lento de la seccion Work por un scroll vertical fijado a pantalla, inspirado en la referencia LML: proyectos grandes en una escena negra, con entrada/salida vertical, blur por profundidad, opacidad progresiva y parallax suave de imagenes.
- Se desactivo el suavizado global con rueda para que el scroll se sienta mucho mas directo y rapido.
- La seccion conserva los modos Overview/Index y los filtros, pero el comportamiento principal del portfolio ahora es el de reel vertical.
